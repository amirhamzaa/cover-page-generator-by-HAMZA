# 🎓 IUBAT Cover Page Generator By HAMZA

A professional, web-based tool designed for students of **IUBAT** to generate high-quality Lab Report and Assignment cover pages instantly.

## 🚀 Live Demo
[[Click Here]](https://amirhamzaa.github.io/cover-page-generator-by-HAMZA/)

---

## ✨ Key Features
* **Flexible Document Type:** Easily switch titles between *Lab Report*, *Assignment*, or *Project Report*.
* **Live Preview:** Real-time A4 sheet preview as you type.
* **Departmental Customization:** Upload your specific department logo and name.
* **Smart Validation:** Prevents downloading if the **Faculty Name**, **Designation**, or **Submission Date** is missing.
* **Fixed Branding:** Keeps the University Name and Logo consistent with official standards.
* **One-Click PDF:** Generates a print-ready PDF using `html2pdf.js`.

---

## 🛠️ Built With
* **HTML5 & CSS3** - Structural layout.
* **Tailwind CSS** - Modern and responsive styling.
* **Vanilla JavaScript** - Live data synchronization and logic.
* **html2pdf.js** - Client-side PDF generation.

---

## 📖 How to Use
1. **Input Information:** Fill in the fields on the left (Department, Course Code, Student Details).
2. **Faculty Details:** Ensure the Faculty Name and Designation are entered (Mandatory).
3. **Set Date:** Choose the submission deadline.
4. **Preview:** Check the right side of the screen to see if everything looks correct.
5. **Download:** Click the **"Download PDF"** button.
